# Simplify Implementation

Review the complete body of work for the current task and simplify it.

- Remove dead code and leftovers from previous attempts.
- Simplify code that no longer needs to be complex.
- Reuse or consolidate code where sharing makes sense.
- Remove unnecessary abstractions, duplication, and temporary scaffolding.
- Preserve intended behavior and avoid unrelated rewrites.
- Run relevant checks after making changes.
